# OpsDrill

**Practice DevOps. Think Production.**

Story-based, bilingual (Hinglish + English) DevOps interview preparation focused on real production reasoning.

## What is inside

- Azure
- Kubernetes
- Terraform
- Docker
- Linux
- CI/CD
- DevSecOps
- Production scenarios
- Troubleshooting drills
- Mock interview mode
- Browser-saved progress and bookmarks

## Content format

Every question is designed around:

1. Real-world story
2. Interviewer question
3. Simple Hinglish explanation
4. Interview-ready English answer
5. Deep dive
6. Practical commands/configuration
7. Production example
8. Common mistakes
9. Senior-level insight
10. Follow-up question

## Run locally

This is a static site. Open `index.html` directly or serve the repository with:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

Go to **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The content is loaded from `content/questions.json`, so adding questions does not require changing the UI.
